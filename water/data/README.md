# Drinking Water Data

This folder contains raw data used for the drinking water access analysis.

## Data Description

Indicators included:

- People using at least basic drinking water services (% of population)
- People using safely managed drinking water services (% of population)

Geography: Dominican Republic  
Time Coverage: 2000–2024 (subject to data availability)  
Source: World Bank World Development Indicators (WHO/UNICEF JMP)

## Notes

- Data files are downloaded directly from the World Bank.
- No cleaning, calculations, or transformations are performed in this folder.
- All analysis and visualization are conducted in the `analysis/` folder.
