# Drinking Water Analysis

This folder contains analysis outputs related to drinking water access in the Dominican Republic.

## Contents

- **DR_Water_Access_Google_Sheets.pdf**  
  Visualizations and tables showing trends in basic and safely managed drinking water access from 2000 to 2024.

## Methodology

- Raw indicator data was imported into Google Sheets.
- National-level data was isolated and reviewed for consistency.
- Percentages were visualized to compare trends between service levels.
- Differences between basic and safely managed access were examined to identify service gaps.

## Tools Used

- Google Sheets
