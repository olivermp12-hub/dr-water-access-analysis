# Drinking Water Access Analysis

This folder contains data and analysis related to access to drinking water in the Dominican Republic from 2000 to 2024.

The analysis compares **basic drinking water access** with **safely managed drinking water access** to highlight differences between availability and service quality over time.

## Indicators Used

- **People using at least basic drinking water services (% of population)**  
  World Bank Indicator Code: `SH.H2O.BASW.ZS`

- **People using safely managed drinking water services (% of population)**  
  World Bank Indicator Code: `SH.H2O.SMDW.ZS`

Source: WHO/UNICEF Joint Monitoring Programme (JMP), accessed via the World Bank World Development Indicators.

## Folder Structure

- **data/**  
  Raw indicator data downloaded from the World Bank.

- **analysis/**  
  Cleaned data, summary tables, charts, and analytical outputs used to examine trends over time.

This structure separates raw data from analysis to ensure transparency and reproducibility.
