# Sanitation Access Analysis

This folder contains data and analysis related to access to basic sanitation services in the Dominican Republic between 2000 and 2024.

## Structure

- **data/**  
  Raw World Bank / WHO-UNICEF JMP indicator data used in the analysis.

- **analysis/**  
  Cleaned tables, calculations, and visual outputs summarizing trends in sanitation access.

## Indicator Used

- People using at least basic sanitation services (% of population)  
- World Bank Indicator Code: SH.STA.BASS.ZS
