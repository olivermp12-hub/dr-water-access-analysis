# Sanitation Access Analysis

This folder contains data and analysis related to access to at least basic sanitation services in the Dominican Republic from 2000 to 2024.

The analysis focuses on national-level trends and highlights long-term changes in sanitation coverage using internationally comparable indicators.

## Indicator Used

- **People using at least basic sanitation services (% of population)**
- World Bank Indicator Code: `SH.STA.BASS.ZS`
- Source: WHO/UNICEF Joint Monitoring Programme (JMP)

## Folder Structure

- **data/**  
  Raw indicator data downloaded from the World Bank.

- **analysis/**  
  Cleaned data, summary tables, and visual outputs used to analyze sanitation access trends.

This separation ensures transparency between raw inputs and analytical outputs.
