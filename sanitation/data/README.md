# Sanitation Data

This folder contains raw data used for the sanitation access analysis.

## Data Description

- Indicator: People using at least basic sanitation services (% of population)
- Indicator Code: SH.STA.BASS.ZS
- Geography: Dominican Republic
- Time Coverage: 2000–2024 (depending on data availability)
- Source: World Bank World Development Indicators (WHO/UNICEF JMP)

## Notes

- Data is downloaded directly from the World Bank without modification.
- No calculations or transformations are performed in this folder.
- All analysis and visualization occur in the `analysis/` folder.
